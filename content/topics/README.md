# Topics

Topic pages are generated in **Phase 3** from book `tags` plus curated
descriptions added here as `content/topics/<slug>.json`:

```json
{
  "slug": "algorithms",
  "label": "Algorithms",
  "description": "Design and analysis of algorithms, complexity, common problem patterns."
}
```

A topic without a file here still gets a page from its tag; the file just adds a
description and controls display.
