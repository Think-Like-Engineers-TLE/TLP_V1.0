# Authors

Author pages are generated in **Phase 3**.

For now, author names come from each book's `author` field. When author entries
are added here, each will be `content/authors/<slug>.json` with:

```json
{
  "slug": "marijn-haverbeke",
  "name": "Marijn Haverbeke",
  "bio": "Short, factual, appropriately sourced.",
  "links": [{ "name": "Website", "url": "https://marijnhaverbeke.nl/" }]
}
```

Only include author information that is appropriately sourced.
