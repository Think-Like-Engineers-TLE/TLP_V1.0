# Security Policy

## Reporting a vulnerability

Think Like Programmer is a static website with no user accounts, no database,
and no server-side application code, so the attack surface is small. If you
still find a security issue:

- **Do not** open a public issue for anything exploitable.
- Use GitHub's **private vulnerability reporting** ("Report a vulnerability" on
  the repository's Security tab), or email the maintainers listed in the
  repository profile.

Please include steps to reproduce and the affected URL or file. We aim to
acknowledge reports within a few days.

## Out of scope

- Reports about the content of third-party sites we link to.
- Missing security headers that are managed by the hosting/CDN layer
  (open an issue instead — these are configuration, not vulnerabilities).

## Copyright / licensing concerns

These are **not** security issues. See [`/legal`](https://thinklikeprogrammer.dev/legal)
or open a normal issue with the `copyright` label.
